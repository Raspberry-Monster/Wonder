# 发言者识别与旧共享数据

## 当前行为

Identity 只描述 Bot 自身。当前消息携带 Conversation 范围内稳定的匿名作者标签，并按已绑定 LogicalUser 的 PreferredName 提供用户主动设置的称呼；未设置时使用自然的“你”，不从助手 Identity 或他人消息猜名字。没有自动采集 QQ 昵称或群名片。

群聊按用户最新决定精简为基础聊天和当前发言者识别，不读取历史、摘要、关系或记忆，不触发 Reflection、记忆维护或群来源向量任务。普通群消息即使因运行策略保存，也不会供后续模型读取。群策略只保留 @、回复触发、前缀及消息保存设置。

## 私人来源与旧数据

私人事实仍由本人授权控制。兼容的 UserShared 副本必须来自 Private 原始事实，且只能由本人在同一 Bot 的私聊中读取；不能流入群聊。群来源的 GroupUser、GroupShared、GlobalPublic、SpaceShared 以及从群来源派生的 UserShared 均退出生成、检索与发送路径。

现有共享空间和数据不做全局物理删除；管理台已移除群共享入口，群策略不再关联空间。旧管理/撤回/清理 API 保留兼容用途，不能使群聊恢复消费记忆。旧群来源的助手历史、私人摘要和待发送输出也会在读取/发送门被排除。

新版事实仍不继承旧共享。本人更正、撤回或删除沿原有授权、Epoch 和版本链处理。用户主动删除或更正一条 Memory 的现有清理范围较宽：会清理该用户在该 Bot 下的原始消息和相关 Session 派生内容；这不是本轮新增的行为。自动归档不触发该原始消息清理。

Notes 是独立授权的数据：Agent Notes 不向用户直接展示，User Notes 可由本人管理。关闭 Notes 授权会立即隔离其上下文；彻底删除通过本人 Notes 隐私入口及可重放账本执行。Memory 来源变化只隔离有明确依赖的 Notes，不顺带清除所有独立笔记。

完整事务、版本来源与恢复边界见 [ADR-013 实施附录](adr-013-implementation.md)、[自主维护记忆](memory-maintenance.md) 和 [运行指南](operations.md)。
