# 跨群记忆与用户称呼

## 每个人自己的称呼

Identity 里的名字只描述 Bot 自己。例如“你的名字是树莓”应当表示助手叫树莓，而不是所有用户都叫树莓。

用户登录控制台后，在“我的记忆”关联自己的 QQ，再在“我的称呼与记忆偏好”填写“希望 Bot 如何称呼我”。称呼绑定到经过验证的发送者，同一个人在不同群和私聊中沿用；无需开启长期记忆。留空时使用自然的“你”，不猜测其他人的名字。

当前消息、历史和滚动摘要包含各自作者的匿名标签及主动设置的称呼；共享记忆也带原作者标签。系统规则要求模型按当前作者选择称呼，Identity 中的名字只属于助手。称呼作为不可信标签处理，不作为系统指令。没有自动采集 QQ 昵称或群名片；用户设置的称呼会明确提供给模型。已经生成的旧摘要不会自动重写，模型仍可能偶尔不遵循指令。

## 两种显式共享

聊天原文、滚动摘要和关系偏好仍属于各自会话。跨群传递的是用户明确选择的长期记忆，不是所有群的完整聊天记录。

- **我的跨群记忆（UserShared）**：只用于本人在同一个 Bot 的其他群或私聊中的对话，其他人不能读取。
- **共享空间（SpaceShared）**：来源群和目标群需要属于同一个 Bot、同一个空间。空间内其他成员也可在对话中使用这条信息。私聊不读取空间记忆。

操作顺序：

1. Bot Owner 在“群聊与共享空间”创建共享空间，把需要互通的群加入同一个空间并保存策略。
2. 记忆作者在“我的记忆”开启长期记忆和逐条跨群共享开关。开启本身不会发布旧记忆。
3. 对需要共享的记忆点击“共享此条”，选择本人跨群或指定空间。私人记忆只能选择本人跨群；空间共享要求记忆来自该空间内的群。
4. 需要停止共享时点击“撤回共享”。空间里的接收者无需开启自己的长期记忆，也能使用已明确共享的空间信息。

来源群退出空间后，原共享会显示暂不可用，不能在旧空间或新空间检索。作者需要重新选择新空间共享。空间删除也会停用对应共享；加入新空间不会自动搬运原有共享。各个 Bot 之间不共享。

## 更正与撤回

撤回共享保留本地原始记忆。更正或删除原始记忆会同时撤回所有共享副本；更正后的新记忆需要重新共享。关闭长期记忆或跨群开关也会撤回本人的既有共享，重新打开不会自动恢复。

系统按记忆来源追踪派生上下文：仅将实际使用过已撤回记忆的助手历史和摘要标为失效，后续生成不再读取；保留历史原文供诊断，并取消关联的尚未发送回复。已经发送到 QQ 的内容不能由本地撤回操作收回。用户主动删除原始记忆仍沿用既有的本人派生数据清理流程。

称呼默认为空、跨群共享默认关闭，已有记忆不会因开启开关而自动发布。缺失作者和来源信息的摘要不会被推测补全。部署、迁移和恢复见 [运行指南](operations.md)。
